## 📖 عن المشروع | About

**Nex Command** هو مشروع مفتوح المصدر يهدف إلى إنشاء **أكبر مكتبة مرجعية لأوامر أنظمة التشغيل** في مكان واحد. المشروع يجمع أوامر **Windows CMD** و **PowerShell** و **Linux Shell** و **macOS Terminal** مع شرح كامل باللغتين العربية والإنجليزية، وأمثلة عملية، ومقارنة بين الأنظمة.

سواء كنت مبتدئًا تتعلم سطر الأوامر، أو محترفًا تبحث عن الأمر المقابل بين الأنظمة — **Nex Command** هو أداتك المثالية.

**Nex Command** is an open-source project that aims to create the **largest command reference library** for operating systems. It brings together **Windows CMD**, **PowerShell**, **Linux Shell**, and **macOS Terminal** commands with full bilingual explanations, practical examples, and cross-platform comparisons.

Whether you're a beginner learning the command line, or a professional looking for the equivalent command across systems — **Nex Command** is your perfect tool.

### 🔄 Cross-Platform Reference

| العملية | ⊞ Windows CMD | ⚡ PowerShell | 🐧 Linux | 🍎 macOS |

## 🗂 هيكل الأمر | Command Structure

كل أمر في **Nex Command** يحتوي على:

```javascript
{
  id: Number,              // رقم تعريف فريد
  category: String,        // الفئة
  system: String,          // النظام
  command: String,         // الأمر
  syntax: String,          // الصيغة الكاملة
  descriptionAr: String,   // شرح عربي مفصل
  descriptionEn: String,   // English description
  examplesAr: Array,       // أمثلة عملية مع شرح
  examplesEn: Array,       // Examples with description
  dangerLevel: String,     // مستوى الخطورة
  crossRef: Object,        // الأوامر المقابلة
  parametersAr: Array,     // الخيارات (عربي)
  parametersEn: Array      // Parameters
}
